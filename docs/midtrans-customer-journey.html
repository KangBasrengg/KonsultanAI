Model Bisnis: Subscription-based SaaS
Jenis Produk: Layanan digital (konsultasi hukum AI, template dokumen hukum, modul pembelajaran hukum)
Target Pengguna: Masyarakat umum, mahasiswa hukum, UMKM, praktisi hukum, instansi pemerintah
Metode Pembayaran yang Diinginkan: Midtrans Snap (transfer bank, e-wallet, kartu kredit/debit)

3. Detail Langkah Customer Journey

1

Halaman Utama (Landing Page)

Pelanggan mengunjungi konsultan-ai.com. Halaman ini menampilkan informasi lengkap tentang layanan: Hero Section, Statistik, Cara Kerja AI, Fitur Unggulan, Demo Interaktif, dan Section Harga.

Pelanggan dapat langsung meng-scroll ke bagian harga atau mengklik tombol "Mulai Konsultasi Gratis" untuk mencoba free trial terlebih dahulu via form Intake.

2

Memilih Paket Berlangganan

Di section "Pilih Paket Sesuai Kebutuhan", pelanggan melihat 4 pilihan paket dengan informasi harga yang transparan:

3

Login / Registrasi Akun

Jika pelanggan belum login, sistem akan menampilkan Auth Modal (pop-up login/registrasi). Pelanggan bisa login menggunakan:

  • Email dan Password (registrasi baru atau login)
  • Google OAuth (Sign in with Google)

Setelah berhasil login, pelanggan otomatis diarahkan ke halaman transaksi (/chat) dengan parameter paket yang dipilih.

4

Halaman Chat / Transaksi (/chat)

Di halaman ini, pelanggan melihat informasi paket yang dipilih, status transaksi ("Proses"), dan tombol "Bayar Sekarang". Pelanggan juga bisa mengirim pesan/pertanyaan ke admin melalui fitur chat real-time.

Halaman ini menampilkan:

  • Nama paket yang dipilih (contoh: "Basic")
  • Status transaksi (Open / Resolved)
  • Riwayat transaksi sebelumnya (sidebar)
  • Tombol "Bayar Sekarang" yang memicu pembayaran Midtrans
5

💳 Proses Pembayaran via Snap Midtrans

Ketika pelanggan menekan tombol "Bayar Sekarang", sistem melakukan hal berikut secara otomatis:

  1. Frontend mengirim request POST ke API endpoint /api/checkout dengan data: chatId, planName, userEmail, userName.
  2. Backend (Next.js API Route) membuat transaksi melalui Midtrans Snap API menggunakan midtrans-client library, menghasilkan Snap Token.
  3. Frontend menerima Snap Token dan memanggil window.snap.pay(token) yang membuka popup/overlay pembayaran Snap Midtrans.
  4. Pelanggan memilih metode pembayaran (Transfer Bank, GoPay, QRIS, Kartu Kredit, dll.) dan menyelesaikan pembayaran.
Detail Teknis Integrasi Midtrans:

Library: midtrans-client (Node.js SDK)
Mode: Snap Pop-up (client-side overlay)
API Endpoint: POST /api/checkout
Webhook: POST /api/webhook/midtrans
Order ID Format: ORD-{timestamp}-{chatId_8char}
Snap JS: Loaded via script tag di layout (app.sandbox.midtrans.com/snap/snap.js)
Signature Verification: SHA-512 (order_id + status_code + gross_amount + server_key)
6

Callback & Status Update

Setelah pembayaran selesai, sistem menangani berbagai callback dari Snap Midtrans:

EventAksi Sistem
onSuccessUpdate status chat → "resolved", upgrade akun user ke plan yang dibeli, kirim pesan otomatis "Terima kasih", reload halaman.
onPendingTampilkan notifikasi "Menunggu pembayaran".
onErrorTampilkan notifikasi "Pembayaran gagal. Silakan coba lagi."
onCloseTampilkan notifikasi "Pembayaran dibatalkan."

Selain itu, Webhook endpoint (/api/webhook/midtrans) menerima notifikasi server-to-server dari Midtrans untuk memastikan konsistensi data meskipun user menutup browser.

7

Akun Terupgrade — Akses Premium

Setelah pembayaran berhasil diverifikasi, akun pelanggan otomatis di-upgrade ke paket yang dibeli. Pelanggan mendapatkan akses ke seluruh fitur premium sesuai tier-nya, termasuk:

  • Generate analisis AI sesuai kuota paket
  • Download laporan PDF
  • Akses template dokumen hukum
  • Akses materi Legal Learning Center
  • AI Legal Tutor (Pro & Enterprise)
